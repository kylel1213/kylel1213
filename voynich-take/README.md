# THE VOYNICH TAKE

A performance capture of Beinecke MS 408 (the Voynich manuscript): the
Takahashi transcription rendered word by word, in manuscript order, on a
16th-note grid at 124 BPM, with the artwork's measured pixel profile driving
the arrangement and the f85v–86r spatial data driving nine circular canons.
Derived, never composed. No functional harmony. The piece ends mid-word.

Everything deliverable lives in [`outputs/`](outputs/README.md):

- `outputs/midi/01..05_*.mid` — one Type-1 SMF per movement (PPQN 480, tempo 124, named tracks, CC automation embedded)
- `outputs/automation/*.csv` — every CC lane as `time_beats, cc, value, track`
- `outputs/preview/voynich_take_full.mp3` — the committed press-play preview (the 44.1 kHz/16-bit WAVs are regenerated by the build; they are ~300 MB and gitignored)
- `outputs/README.md` — Logic Pro import steps, track/patch manifest, acceptance battery results
- `outputs/battery.json` — the same battery as data

## Rebuild

```bash
pip install mido numpy lameenc
mkdir data && cd data
git clone --depth 1 https://github.com/OrcusLabs/voynich.science.git vjson
git clone --depth 1 https://github.com/alessandroplaca-uro/voynich-spatial-data.git spatial
cd ..
python build.py --data data            # ~2 min; --no-render skips the WAV
```

The build is deterministic (seed 408). If the transcription cannot be
fetched, `--fallback` runs the replica machine (synthetic text) and the README
says so loudly.

## Layout

| file | role |
|---|---|
| `voynich/corpus.py` | TTLI transcription → folios/lines/words, manuscript order, paragraph marks, `$I` sections |
| `voynich/pitch.py` | glyph frequency rank → D Dorian pool, inertia rule, stem stripping |
| `voynich/compiler.py` | line = bar group, thinning, PARAGRAPH_VOICE / LABEL_HITS / ROOT_BASS / GREEN_PAD compilers, burst-gap scheduler, folio subsampling |
| `voynich/rosettes.py` | the nine `C*.ring` polygons → loops ordered by angle, staggered by centre x |
| `voynich/movements.py` | the five movements, BLUE_BELL budget, YEAR_CLOCK, mid-word truncation, no-reprise rule, drift lane |
| `voynich/automation.py` | CC1 / CC11 stepped per folio, CC74 A→B morph, CSV export |
| `voynich/midiwrite.py` | SMF writer (mido) |
| `voynich/battery.py` | the acceptance battery (§9) |
| `voynich/render.py` | pure-Python preview synth (numpy) + MP3 copy |
| `voynich/replica.py` | fallback text generator (§8) |
